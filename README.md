# YourOwn Platform

Shared infrastructure core for YourOwn projects on Google Cloud and AWS, with Cloudflare and administrative MCP integrations.

This repository is being bootstrapped. The initial implementation will be reviewed in a separate pull request. No cloud resources are managed by this initial commit.

## Boundaries

Platform infrastructure and reusable delivery contracts belong here. Product application code, deployed infrastructure inventory, IP addresses, credentials, Terraform state and plans do not.

## Licensing

The source is public. An explicit open-source license remains a maintainer decision before the first release.
